# عاش العراق

صفحة عربية عراقية ثابتة، بلا تبعيات بناء أو قاعدة بيانات. شغّلها من خادم HTTP ثابت؛ يجب ألا تُفتح عبر `file://` لأن `app.js` يُحمّل كوحدة JavaScript عند الدخول. بيانات الحساب والمهام واليوميات تبقى في `localStorage` على جهاز المستخدم.

- `index.html`: بنية الصفحة والروابط.
- `legacy.css`: الأنماط الأصلية المنقولة خارج HTML.
- `styles.css`: التنسيق الجديد المتجاوب.
- `boot.js`: بوابة الدخول وتحميل التطبيق عند الحاجة.
- `app.js`: منطق الموقع.
- `motion.js`: الحركة التدريجية وإمكانية تقليل الحركة.
- `manus-routes.json`: بيان المسارات.
- `icon.svg`: أيقونة الموقع.

للنشر الثابت، ارفع الملفات المذكورة أعلاه معًا إلى جذر الموقع. أمر بناء WebDev ينسخ جميع موارد الصفحة إلى `dist/`.
