# عاش العراق

صفحة عربية عراقية مستقلة. شغّلها عبر خادم ملفات ثابت أو افتح `index.html` مباشرة. لا تحتاج إلى Node dependencies أو قاعدة بيانات؛ بيانات الملف الشخصي والمهام واليوميات وغيرها تبقى في `localStorage` على جهاز المستخدم.

- `index.html`: المحتوى والمنطق الأصلي.
- `styles.css`: التصميم المتجاوب.
- `manus-routes.json`: بيان مسارات الصفحة.
- `icon.svg`: أيقونة الموقع.

للنشر الثابت، ارفع ملفات HTML وCSS وSVG وJSON معًا إلى جذر الموقع.
